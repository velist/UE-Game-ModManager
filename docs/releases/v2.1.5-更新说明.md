# 爱酱 MOD 管理器 v2.1.5 更新说明

发布日期：2026-11-24　·　安装包：`UEModManager_v2.1.5_Setup.exe`

覆盖安装即可，已导入的 MOD、方案和设置都会保留。升级前请先关闭管理器和游戏。

---

## 修复：临时数据不再占满 C 盘

有玩家反馈：MOD 仓库和备份都放在别的盘了，C 盘还是被管理器越占越多。这一版修掉了。

- **不再往 C 盘堆没用的副本。** 以前每次启用/禁用 MOD，都会在 C 盘多留一份文件副本，而且从不清理。现在不再生成，以前攒下的会自动删除。
- **部署备份跟着 MOD 仓库走。** 仓库在 D 盘，备份就在 D 盘，不再写系统盘。
- **旧备份自动清理。** 只保留最近 10 次、3 天内、总共不超过 2 GB 的部署备份（最近一次始终保留）。
- **定时清理。** 打开管理器约 1 分钟后清一次，之后每 6 小时清一次；导入压缩包时被强制关闭留下的临时文件也会一并清掉。

你不需要做任何操作：升级后正常打开管理器，等一两分钟，C 盘空间就会回来。

> MOD 仓库还在默认位置的话，备份位置不变，只是会按上面的规则自动清理。想彻底腾出 C 盘，请在设置里把 MOD 仓库改到其它盘。

## 同时包含 v2.1.4 的修复

- 影之刃零的 MOD 在冲突分析里显示「无法分析」的问题已修复。
- 分开拖入的 `.pak / .utoc / .ucas` 三件套现在会合成一个 MOD。
- 导入时的文件选择框按当前游戏显示对应的 MOD 文件类型。
