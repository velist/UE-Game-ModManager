- README 中英文、官网首页与帮助页的游戏列表、两份图标来源表、CLAUDE.md

## 实装核对（2026-10-29，Steam buildid 26266538）

| 项 | 实际值 |
| --- | --- |
| 游戏根目录 | `steamapps\common\PBZ`（约 143 GB） |
| 启动壳 | `steam\PBZ.exe`（约 1 MB，Steam 配置的启动项）→ 管理器启动用它，游戏路径记为 `PBZ\steam` |
| 游戏本体 | `platform\steam\PBZ.exe`（约 511 MB）；**没有** `*-Win64-Shipping.exe` |
| UE 工程目录 | `ProjectPBZ`（`ProjectPBZ\Binaries\Win64` 只有 8za_v2 / CheckEnv / crashpad_handler） |
| MOD 目录 | `ProjectPBZ\Content\Paks\~mods`（Paks 为 UE5 IoStore：pak + utoc + ucas，**无 .sig 签名**） |
| 其他平台 | 插件里有 WeGameSDK / TapTapSDK，非 Steam 版目录名未知；找根目录时以"含 `ProjectPBZ` 子目录"判定 |

已按实装修正：
- `GameConfigService.MatchPhantomBladeZero`：两个同名 `PBZ.exe` 里优先非 `platform\` 下的启动壳，没有时退回本体
- `GamePathDialog`：exe 选择复用上述规则；`gameSpecificModPaths["影之刃零"]` 改为 `ProjectPBZ\...`；
  `FindGameRootDirectory` 认 `ProjectPBZ` 子目录
- 测试：`SelectExecutable_PhantomBladeZero_PrefersSteamLauncherOverPlatformBinary`、
  `AutoDetectExecutable_PhantomBladeZeroRoot_FindsSteamLauncher`、`PhantomBladeZero_IsBuiltInUnrealGame`
