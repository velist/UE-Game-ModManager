# 爱酱 MOD 管理器 v2.1.3 更新说明

发布日期：2026-10-29　·　安装包：`UEModManager_v2.1.3_Setup.exe`

覆盖安装即可，已导入的 MOD、方案和设置都会保留。升级前请先关闭管理器和游戏。

---

## 新增游戏：影之刃零

- 游戏列表里直接选「影之刃零」，点自动检测就能找到游戏和 MOD 文件夹（`ProjectPBZ\Content\Paks\~mods`）。
- 从管理器「启动游戏」走的是 Steam 同款启动方式，和在 Steam 里点开始一样。
- 下载的 .pak / .utoc / .ucas MOD 直接拖进来导入、启用即可。

> 影之刃零刚发售，MOD 是否需要额外的前置工具（如 UE4SS），请以 MOD 作者说明为准。
