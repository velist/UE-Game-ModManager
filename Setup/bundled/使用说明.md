# 爱酱 MOD 管理器使用说明

适用版本：2.1.3 · 更新日期：2026-10-29

## 安装与首次启动

支持 Windows 10 / 11 的 64 位环境。本发行包需要 **.NET 8 Desktop Runtime（x64）**，安装向导会检查是否已就绪。缺少时，请通过向导中的按钮前往微软官方网站安装桌面运行时。

1. 选择程序安装位置。桌面快捷方式默认开启，开机启动默认关闭，可自行调整。
2. 首次启动按提示选择 **MOD 仓库**。这是 MOD 文件的存储位置，与程序安装位置分别设置。建议选空间充足的非系统盘，程序不会推荐系统盘；点“以后再说”且仓库还是空的时，程序会自动改到空间最大的非系统盘（`盘根\UEModManager\Repository`），只有一块系统盘时保持默认位置。
3. 主界面第一次出现时有 4 步引导（选游戏 → 导入 → 启用和管理 → 启动游戏），可跳过，只出现一次。
4. 添加或选择游戏，确认游戏路径及 MOD 部署位置。
5. 导入 MOD，核对后启用，再启动游戏。

启动时不会弹出登录窗口，核心 MOD 管理无需登录，账号入口在左侧边栏底部。账号功能不提供 MOD 文件云同步。内置支持剑星、黑神话：悟空、明末：渊虚之羽、光与影等游戏，具体以程序列表为准，也可添加自定义游戏。

## 导入与管理 MOD

可使用“导入”按钮，或把文件、文件夹拖入主窗口。可直接导入 ZIP 压缩包、解压后的文件夹，以及 PAK、UTOC、UCAS、DLL、LUA、INI 等文件；**RAR / 7Z 压缩包请先用 WinRAR 或 7-Zip 解压再导入**。UTOC / UCAS 等成组文件应一起导入，游戏额外需要的前置组件请遵循 MOD 作者说明。

导入确认窗口会列出每个文件的安装位置。看起来是游戏自带原版文件的（如 `pakchunk0-Windows.pak`、官方补丁 `pakchunk26-Windows_P.pak`、`re_chunk_000.pak`）默认不勾选，确认是 MOD 时可手动勾上；单独拖入的说明、图片、网页文件会被跳过；同名 MOD 会另存为新名字，不会覆盖。

每张卡片左上角标明类型：**MOD**（替换游戏资源，放进游戏的 MOD 文件夹）、**插件**（UE4SS、REFramework 等加载器运行的脚本或 DLL，装在游戏目录里）、**配置**（.ini / .json 等设置文件）。列表上方可按“全部 / MOD / 插件 / 配置”切换，仓库里只有 MOD 时不显示。

导入后可给 MOD 分类，并通过开关启用或禁用。导入完成不代表已经部署到游戏。修改后请查看操作结果；游戏运行期间先关闭游戏，再调整 MOD。“删除”会同时删除管理器里保存的文件，只想暂时不用请选“禁用”。

分类可通过左侧列表管理；也可右键 MOD 使用“移动到分类”。方案用于保存不同的 MOD 组合，切换方案时会自动部署；部署失败会留在原方案，游戏文件恢复原样。

## 冲突与恢复

两个 MOD 替换同一游戏资源且内容不同才算冲突，卡片上以红色数字标出，内容相同只标“重复”。冲突面板里每组冲突一个按钮（“禁用 X”或“只保留 X”），点击即生效并重新部署，处理期间会显示进度。部署失败或恢复提示出现时，先保存错误信息，按界面提供的恢复操作处理。不要直接删除事务记录和部署备份。

游戏更新改写了 MOD 已装入的文件时，禁用或删除该 MOD 会提示“文件已被游戏更新”，选“交给游戏（推荐）”即可。游戏更新后，原 MOD 可能需要更新，应遵循游戏和 MOD 作者的兼容性说明。

## 文件位置与备份

| 内容 | 位置 |
|---|---|
| 程序文件 | 安装时选择的目录 |
| 游戏配置、索引等本机数据 | `%LOCALAPPDATA%\UEModManager\` |
| 界面偏好、账号等数据 | `%APPDATA%\UEModManager\` |
| MOD 仓库 | 首次启动或“设置 → MOD 文件与位置”中选择的位置；跳过时自动放到非系统盘的 `UEModManager\Repository\`，只有系统盘时为 `%LOCALAPPDATA%\UEModManager\Repository\` |
| 备份 | 设置中指定的位置；默认根为 `%LOCALAPPDATA%\UEModManager\Backups\`，游戏备份也可能位于游戏所在盘的 `UEModManager\Backups\Mods\` |
| 日志 | `%LOCALAPPDATA%\UEModManager\Logs\`；旧版本可能留在程序目录 |

换电脑或重装前，请先关闭管理器与游戏，备份上述两个用户数据目录，以及实际使用的 MOD 仓库、生成物和备份目录。只复制漫游数据目录不能备份全部 MOD。恢复时先保留现有目录副本，再按原路径恢复，并核对新电脑上的游戏路径。

## 升级与卸载

覆盖安装保留已有用户数据和仓库，升级前请关闭管理器。旧版本数据可使用随包的 `一键迁移老版本数据.bat`：它备份配置、索引等数据后启动程序；大型 MOD 仓库及备份目录需要另行备份，脚本备份不能代替完整 MOD 文件副本。

普通卸载会保留用户数据、MOD 仓库和部署备份。随包的 `彻底清理UEModManager用户数据.bat` 是额外的手动清理工具，执行前请阅读脚本提示并备份所需内容。

## 联网与隐私

“检查更新与匿名统计”**默认关闭**，首次启动不会询问，需要在“设置 → 常规参数”中主动打开。打开后发送随机设备编号、软件与 Windows 版本；登录时附带邮箱哈希。统计不上传邮箱明文、电脑名、文件路径、游戏目录或 MOD 清单，随时可以关闭。统计关闭时仍会在启动后查询一次最新版本号（不带任何标识），新版本提示不受影响。登录、注册、找回密码等操作会分别发送其所需的账号信息。

完整说明见安装目录的 `LICENSE.txt` 与[官网隐私说明](https://www.modmanger.com/help#privacy)。
