# 爱酱 MOD 管理器使用说明

适用版本：2.1.0 · 更新日期：2026-09-09

## 安装与首次启动

支持 Windows 10 / 11 的 64 位环境。本发行包需要 **.NET 8 Desktop Runtime（x64）**，安装向导会检查是否已就绪。缺少时，请通过向导中的按钮前往微软官方网站安装桌面运行时。

1. 选择程序安装位置。桌面快捷方式默认开启，开机启动默认关闭，可自行调整。
2. 首次启动按提示选择 **MOD 仓库**。这是 MOD 文件的存储位置，与程序安装位置分别设置。
3. 添加或选择游戏，确认游戏路径及 MOD 部署位置。
4. 导入 MOD，核对后启用，再启动游戏。

核心 MOD 管理无需登录。账号功能不提供 MOD 文件云同步。内置支持剑星、黑神话：悟空、明末：渊虚之羽、光与影等游戏，具体以程序列表为准，也可添加自定义游戏。

## 导入与管理 MOD

可使用“导入”按钮，或把文件拖入主窗口。支持常见 ZIP、RAR、7Z 压缩包，以及 PAK、UTOC、UCAS 等文件。UTOC / UCAS 等成组文件应一起导入，游戏额外需要的前置组件请遵循 MOD 作者说明。

导入后可给 MOD 分类、调整顺序，并通过开关启用或禁用。导入完成不代表已经部署到游戏。修改后请查看操作结果；游戏运行期间先关闭游戏，再调整 MOD。

分类可通过左侧列表管理；也可右键 MOD 使用“移动到分类”。方案用于保存不同的 MOD 组合。需要将方案应用到游戏时，请执行相应应用操作并确认部署结果。

## 冲突与恢复

多个 MOD 覆盖同一位置时，可通过冲突分析核对来源、优先级与选择结果。部署失败或恢复提示出现时，先保存错误信息，按界面提供的恢复操作处理。不要直接删除事务记录和部署备份。

删除 MOD 前请先禁用，并检查它是否仍被其他方案引用。游戏更新后，原 MOD 可能需要更新，应遵循游戏和 MOD 作者的兼容性说明。

## 文件位置与备份

| 内容 | 位置 |
|---|---|
| 程序文件 | 安装时选择的目录 |
| 游戏配置、索引等本机数据 | `%LOCALAPPDATA%\UEModManager\` |
| 界面偏好、账号等数据 | `%APPDATA%\UEModManager\` |
| MOD 仓库 | 首次启动或设置中选择的位置；未指定时为 `%LOCALAPPDATA%\UEModManager\Repository\` |
| 备份 | 设置中指定的位置；默认根为 `%LOCALAPPDATA%\UEModManager\Backups\`，游戏备份也可能位于游戏所在盘的 `UEModManager\Backups\Mods\` |
| 日志 | `%LOCALAPPDATA%\UEModManager\Logs\`；旧版本可能留在程序目录 |

换电脑或重装前，请先关闭管理器与游戏，备份上述两个用户数据目录，以及实际使用的 MOD 仓库、生成物和备份目录。只复制漫游数据目录不能备份全部 MOD。恢复时先保留现有目录副本，再按原路径恢复，并核对新电脑上的游戏路径。

## 升级与卸载

覆盖安装保留已有用户数据和仓库，升级前请关闭管理器。旧版本数据可使用随包的 `一键迁移老版本数据.bat`：它备份配置、索引等数据后启动程序；大型 MOD 仓库及备份目录需要另行备份，脚本备份不能代替完整 MOD 文件副本。

普通卸载会保留用户数据、MOD 仓库和部署备份。随包的 `彻底清理UEModManager用户数据.bat` 是额外的手动清理工具，执行前请阅读脚本提示并备份所需内容。

## 联网与隐私

“检查更新与匿名统计”在获得同意后发送随机设备编号、软件与 Windows 版本；登录时可能附带邮箱哈希。统计不上传邮箱明文、电脑名、文件路径、游戏目录或 MOD 清单，可在“设置 → 常规参数”中关闭。登录、注册、找回密码等操作会分别发送其所需的账号信息。

完整说明见安装目录的 `LICENSE.txt` 与[官网隐私说明](https://www.modmanger.com/help#privacy)。
