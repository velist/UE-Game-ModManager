# 爱酱 MOD 管理器使用说明书

适用版本：**2.1.2** · 更新日期：**2026-10-23**

爱酱 MOD 管理器是面向普通玩家的游戏 MOD 管理工具：导入、启用、冲突处理、方案切换、备份恢复都能一键完成。支持多种游戏引擎（虚幻、RE 引擎、Godot、暗黑破坏神 4 等），内置黑神话：悟空、剑星、光与影：33号远征队、明末：渊虚之羽、暗黑破坏神 4、生化危机 9、无主之地 4、死亡搁浅 2、杀戮尖塔 2 等游戏，具体以程序内列表为准；列表里没有的游戏也可以自己添加。

核心 MOD 管理**不需要注册账号，不联网也能用**。

> **一分钟速通**：安装 → 选 MOD 存放位置（别选 C 盘）→ 选游戏 → 导入 MOD → 启用 → 点「启动游戏」开玩。

---

## 一、安装

1. 系统要求：Windows 10 / 11 64 位。
2. 需要 **.NET 8 桌面运行时（x64）**。安装向导会自动检查，缺少时点向导里的按钮去微软官网下载安装，装完回来继续。
3. 双击 `UEModManager_v2.1.2_Setup.exe`，选择安装位置。桌面快捷方式默认开启，开机启动默认关闭，可自行调整。

**从旧版本升级**：直接覆盖安装即可，已导入的 MOD、方案和设置都会保留。升级前请先关闭管理器和游戏。

---

## 二、第一次启动

### 1. 选择 MOD 存放位置（MOD 仓库）

第一次打开会出现「MOD 存储设置」窗口。这里选的是 **MOD 仓库**——导入的 MOD 都先存在这里，不会和游戏文件混在一起。

- 程序会列出你电脑上的磁盘，并给出推荐。**建议选一个空间充足的非系统盘**（不要放 C 盘），程序也不会推荐系统盘。
- 选好后点「使用此位置」。
- 暂时不想选可以点「以后再说」。此时如果你的电脑有其他硬盘，程序会自动把仓库放到**空间最大的非系统盘**，例如 `D:\UEModManager\Repository`；只有一块系统盘时才会留在默认位置。
- 你自己选过的位置（哪怕是 C 盘），程序都不会擅自改动。
- 以后想换位置：「设置 → MOD 文件与位置 → MOD 文件保存位置」。

### 2. 跟着首次使用引导走一遍

主界面第一次出现时，会有一个 4 步的小引导，用聚光灯依次指给你看：

1. **先选游戏**：在哪里选择要装 MOD 的游戏；
2. **导入 MOD**：导入按钮在哪；
3. **启用和管理**：MOD 卡片区域怎么用；
4. **开始游戏**：从哪里启动游戏。

可以点「下一步」看完，也可以按 Esc 或点跳过。引导只出现一次。

### 3. 不会再弹登录窗口

打开程序直接进入主界面。需要账号功能时，点左侧边栏底部的「点击登录账号」。账号不提供 MOD 文件的云端存储。

---

## 三、选择游戏与路径

1. 点左侧边栏顶部的「当前游戏」，选中要玩的游戏。
2. 弹出「游戏路径配置」时，核对两个路径，不对就点「浏览」修改：

   | 项目 | 例子（黑神话：悟空） |
   |---|---|
   | 游戏安装路径 | `...\BlackMythWukong\b1\Binaries\Win64` |
   | MOD 文件夹路径 | `...\BlackMythWukong\b1\Content\Paks\~mods` |

3. 核对无误点「确认」。

以后修改路径：「设置 → 游戏路径」。列表里没有的游戏，可以在游戏列表里「添加游戏」并选择引擎类型。

---

## 四、导入 MOD

### 导入方式

- 点顶部的「导入」按钮选择文件；
- 或者直接把文件 / 文件夹**拖进主窗口**。

### 支持的格式

- **ZIP 压缩包**、解压后的**文件夹**，以及 .pak / .utoc / .ucas / .dll / .lua / .ini 等 MOD 文件。
- **RAR / 7Z 压缩包请先用 WinRAR 或 7-Zip 解压**，再把解压出的文件夹或文件导入。直接拖入 RAR / 7Z 时程序会提示你先解压（避免解压失败或中文文件名乱码）。
- 一个 MOD 有多个文件（如 .pak + .utoc + .ucas）时，请**一起导入**。

### 导入确认窗口

导入前会弹出「导入确认」，列出每个文件将安装到哪里，核对后点「确认导入」。这里有几种情况需要知道：

| 你看到的 | 意思 |
|---|---|
| 某个文件**默认没勾选**，提示"看起来是游戏自带的原版文件" | 例如 `pakchunk0-Windows.pak`、官方补丁 `pakchunk26-Windows_P.pak`、`global.utoc`、`re_chunk_000.pak`。这些多半是从游戏目录误拖进来的，启用后可能让游戏打不开。**如果你确定它就是 MOD，可以手动勾上。** |
| 提示"已有同名 MOD，导入后会另存为新名字" | 不会覆盖原来那个，两个都会保留。 |
| 提示"仓库已有相同内容的 MOD" | 内容完全一样，不会存两份。 |
| 提示"不是 MOD 文件（说明、图片或网页），已跳过" | 单独拖进来的 readme、图片、网页会被跳过。 |

导入成功后，窗口右上角会出现一条小提示，告诉你导入了几个、是否已经启用。

> **导入 ≠ 已生效。** 默认导入后还要手动启用。想导入后自动启用，可在「设置 → MOD 文件与位置 → 导入后自动启用」打开。

---

## 五、MOD / 插件 / 配置 怎么区分

从 2.1.2 起，导入的东西会自动分成三类，每张卡片**左上角有类型标签**，鼠标停在标签上会显示一句解释：

| 标签 | 是什么 | 装到哪里 | 常见文件 |
|---|---|---|---|
| **MOD** | 替换模型、贴图、音效等游戏资源 | 游戏的 MOD 文件夹 | .pak / .utoc / .ucas，Godot 的 .pck，暗黑 4 的 .mpq 等 |
| **插件** | 由加载器（如 UE4SS、REFramework）运行的脚本或 DLL，给游戏加新功能 | 游戏目录下 | .dll / .asi / .lua |
| **配置** | 修改游戏设置的文件 | 游戏目录下 | .ini / .json / .cfg |

- **类型切换**：MOD 列表标题右边有「全部 / MOD / 插件 / 配置」切换，后面的数字是数量。点一下只看这一类。仓库里只有 MOD 时这排切换会自动隐藏。
- **列表模式**下同样会显示类型标签。
- **详情面板**：点一下 MOD，右侧滑出的面板里会显示「类型」和「安装到」（游戏的 MOD 文件夹 / 游戏目录下），标题和按钮也会按类型称呼（如「插件详情」「启用插件」）。
- 一个包里既有 .pak 又有 .dll 时，按 MOD 算。

## 六、启用、禁用与整理

### 启用 / 禁用

- **鼠标移到卡片上**，点中间出现的电源按钮即可启用或禁用（只认鼠标左键）。卡片右上角的小圆点亮绿色 = 已启用。
- 或者**点一下 MOD**，在右侧详情面板里开关。
- **批量操作**：先勾选（或点「全选」），再点顶部的「启用」/「禁用」。

> 改 MOD 之前，先把游戏关掉。

### 整理

点一下任意 MOD，右侧详情面板里可以：

- 改名字：「编辑名称」
- 写备注：「编辑描述」
- 换预览图：点面板里的图片
- 改分类：「移动到分类」
- 删除：「删除」（会先弹确认）

其他：

- 左侧「分类目录」管理分类；右键 MOD、或卡片的「⋯」菜单里也有「移动到分类」。
- 顶部搜索框按名字找 MOD；可按名称、大小、安装日期排序；右上角切换卡片 / 列表视图。

### 删除和禁用的区别

- **禁用**：MOD 从游戏里撤下，但仍保存在管理器里，随时可以再启用。
- **删除**（含批量「删除」）：从游戏里移除，并**删除管理器里保存的文件**，之后要重新导入才能找回。只想暂时不用，请选「禁用」。

---

## 七、方案（MOD 组合存档）

「MOD 配置方案」用来保存不同的 MOD 组合，比如"画质档"和"战斗档"。

- 在方案管理里**双击一个方案即可切换**。切换时程序会**自动把新方案部署进游戏**。
- 万一部署失败，会**留在原方案**，游戏文件也会恢复原样，并告诉你原因。
- 导入整合包时会自动生成方案并尝试切换过去；切换失败时同样留在原方案，稍后可在方案列表里双击重试。

---

## 八、部署并启动游戏

1. 点顶部绿色的「启动游戏」按钮，打开「启动中心」。
2. 启动中心会自动做启动前检查（有没有冲突、文件是否就位），然后把启用的 MOD 部署进游戏。
3. 检查通过后点「启动游戏」开玩。

> 「部署」= 把启用的 MOD 放进游戏目录。程序采用**复制**方式部署：MOD 仓库始终保留独立的一份，游戏目录里发生什么都不会影响仓库里的文件。

---

## 九、冲突处理

两个 MOD 替换了**同一个游戏资源、而且内容不一样**，才算冲突。内容完全相同的重叠只标"重复"，不算冲突。

### 怎么发现

- 卡片上出现**红色数字** = 这个 MOD 有几组冲突；灰色「重复」标签 = 与别的 MOD 有内容相同的部分。
- 右键 MOD →「查看冲突」，或点顶部的「冲突检测」。
- 启动中心的启动前检查也会提示。

### 怎么处理

- 面板里**一个冲突组配一个按钮**，按钮上直接写着 MOD 名：两个 MOD 冲突显示「禁用 X」，三个及以上显示「只保留 X」。
- **点一下就立即生效**并重新部署，没有"应用"按钮。处理过程中窗口会显示"正在处理冲突并重新部署…"，等它结束即可。
- 删除重复的 MOD 会先弹确认框。
- 拿不准就先「禁用」其中一个，进游戏看效果，不满意再换。

---

## 十、游戏更新后

- 游戏大版本更新后，原来的 MOD 可能失效，需要等 MOD 作者更新。
- 如果游戏更新**改写了 MOD 装进去的文件**，你在禁用或删除这个 MOD 时会看到「文件已被游戏更新」提示。选「**交给游戏（推荐）**」：这些文件按游戏现在的版本保留、以后不再由管理器管理，MOD 的其余部分照常处理。为了安全，管理器不会自动删除被游戏改过的文件。

---

## 十一、外观与背景图

「设置 → 外观设置」里可以自定义主界面背景：

- **背景模式**：默认渐变 / 自定义图片（点「选择图片」）/ 纯色背景。
- **背景透明度**、**背景模糊度**：拖动滑动条调整，也可以直接点轨道上的任意位置跳过去。
- **应用到弹窗**：打开后弹窗也显示同样的背景效果。

调整完点「保存设置」。

此外，界面带有按压回弹、卡片悬停、列表入场等动效。如果你在 Windows 设置里关闭了「显示动画」，这些动效会自动关掉。

---

## 十二、存储、备份与恢复

### 文件位置

| 内容 | 位置 |
|---|---|
| 程序文件 | 安装时选择的目录 |
| MOD 仓库 | 首次设置时选择的位置；跳过时自动放到非系统盘的 `UEModManager\Repository`，可在「设置 → MOD 文件与位置」查看 |
| 游戏配置、索引等本机数据 | `%LOCALAPPDATA%\UEModManager\` |
| 界面偏好、账号等数据 | `%APPDATA%\UEModManager\` |
| 备份 | 「设置 → 游戏路径 → 备份文件夹路径」；默认在 `%LOCALAPPDATA%\UEModManager\Backups\`，游戏备份也可能在游戏所在盘的 `UEModManager\Backups\Mods\` |
| 日志 | `%LOCALAPPDATA%\UEModManager\Logs\` |

### 存储与恢复

左侧边栏「存储与恢复」打开高级管理，可以：

- 查看 MOD 占用、未使用和重复文件，清理可删除的文件；
- 在「安装记录」里**回滚**之前的部署，把游戏目录恢复原样；
- 清理导入残留的临时文件；
- 导出诊断包。

部署中断或出现恢复提示时，按界面提供的恢复操作处理，**不要手动删除安装记录和部署备份**。

### 换电脑或重装

先关闭管理器和游戏，备份：`%LOCALAPPDATA%\UEModManager\`、`%APPDATA%\UEModManager\`，以及实际使用的 MOD 仓库和备份目录。恢复时按原路径放回，并在新电脑上重新核对游戏路径。

---

## 十三、升级与卸载

- **升级**：覆盖安装，保留已有数据。很老的版本可使用安装目录里的 `一键迁移老版本数据.bat`，它会备份配置和索引后启动程序；大型 MOD 仓库及备份目录需另行备份。
- **卸载**：控制面板卸载即可，用户数据、MOD 仓库和部署备份会保留。
- **彻底清理**：运行安装目录里的 `彻底清理UEModManager用户数据.bat`，执行前请阅读脚本提示并备份需要的内容。

---

## 十四、联网与隐私

- **统计默认关闭**：新安装不会上报任何统计，首次启动也不会弹询问。
- 想帮我们了解有多少人在用，可以到「**设置 → 常规参数 → 检查更新与匿名统计**」手动打开。打开后，启动时会发送：随机设备编号、软件版本、Windows 版本；登录后附带邮箱的哈希值（不是邮箱本身）。**不上传**邮箱明文、电脑名、文件路径、游戏目录和 MOD 清单。随时可以关掉。
- **新版本提示不受这个开关影响**：统计关闭时，启动后只查询一次最新版本号，不发送设备编号等任何标识；有新版本时主窗口顶部会出现提示条，点「去下载」直达官网。
- 登录、注册、找回密码时，会分别发送其所需的账号信息。

完整说明见安装目录的 `LICENSE.txt` 与[官网隐私说明](https://www.modmanger.com/help#privacy)。

## 十五、常见问题

| 遇到的情况 | 怎么办 |
|---|---|
| MOD 装了没生效 | ① 卡片右上角圆点是不是绿的？② 走一遍「启动游戏」让它部署；③ 有没有冲突（看红色数字）；④ 是否选对了游戏、清空了搜索和分类筛选 |
| 拖进 RAR / 7Z 提示先解压 | 用 WinRAR 或 7-Zip 解压后，把文件夹或里面的 MOD 文件拖进来 |
| 导入确认里有文件没被勾选 | 它看起来像游戏原版文件。确定是 MOD 就手动勾上 |
| 我的 MOD 被标成了「插件」或「配置」 | 按文件类型自动判断：含 .dll / .asi / .lua 的算插件，只有 .ini / .json 等的算配置。类型只影响显示和安装位置说明 |
| 看不到「全部 / MOD / 插件 / 配置」切换 | 仓库里只有 MOD 时会自动隐藏 |
| 想再看一次首次引导 | 引导只出现一次，本说明书第二节有完整步骤 |
| 设置页点「保存设置」报仓库迁移错误 | 2.1.2 已修复，请升级 |
