# 爱酱 MOD 管理器 v2.1.2 更新说明

发布日期：2026-10-23　·　安装包：`UEModManager_v2.1.2_Setup.exe`

覆盖安装即可，已导入的 MOD、方案和设置都会保留。升级前请先关闭管理器和游戏。

---

## 新功能

- **MOD / 插件 / 配置 分开显示**
  每张卡片左上角多了一个类型标签：
  - **MOD**：替换模型、贴图、音效的资源包（如 .pak），放进游戏的 MOD 文件夹；
  - **插件**：UE4SS、REFramework 这类加载器运行的脚本或 DLL，装在游戏目录里；
  - **配置**：.ini / .json 这类改游戏设置的文件。
  鼠标停在标签上有一句白话解释。
- **类型切换**：列表上方新增「全部 / MOD / 插件 / 配置」切换，后面带数量。仓库里只有 MOD 时这一排会自动隐藏。
- **详情面板更清楚**：点开 MOD 能看到它是什么类型、会装到哪里（「游戏的 MOD 文件夹」或「游戏目录下」）。
- **首次使用引导**：第一次打开时，会用 4 步带你认识：选游戏 → 导入 → 启用和管理 → 启动游戏。可随时跳过，只出现一次。
- **新版本提示**：有新版本时，主窗口顶部会出现提示条，点「去下载」直达官网。不开统计也能收到。
- **游戏更新后的文件，可以"交给游戏"**：游戏更新改写了 MOD 装进去的文件时，禁用或删除这个 MOD 会提示你，选「交给游戏（推荐）」即可，MOD 的其余部分照常处理，不再卡住。
- **切换方案就自动部署**：在方案管理里切换方案，会直接把新方案装进游戏；万一失败，会留在原方案，游戏文件也会恢复原样。

## 体验改进

- **界面动起来了**：按钮按下有回弹，卡片悬停会轻轻浮起，列表刷新时逐张出现，对话框弹出更顺滑，操作失败时提示框会轻轻一抖，管理中心的统计数字会滚动到位。Windows 里关闭了「显示动画」的话，这些动效会自动关掉。
- **导入成功有提示了**：导入完成后右上角会冒出一条小提示，告诉你导入了几个、是否已启用。
- **MOD 仓库不再默认放 C 盘**：首次设置时不会再推荐系统盘；如果你当时点了「以后再说」，而仓库还是空的，程序会自动把它放到空间最大的非系统盘（例如 `D:\UEModManager\Repository`）。你自己选过的位置不会被改动。
- **统计默认关闭，首次启动不再打扰**：去掉了首次启动底部的统计询问条。新安装默认不上报任何统计，想帮忙可以到「设置 → 常规参数 → 检查更新与匿名统计」自己打开。
- **启动不再弹登录窗口**：打开就直接进主界面。需要账号时点左下角「点击登录账号」。
- **冲突处理时有进度**：在冲突窗口里点「禁用 / 只保留」时，窗口上会显示"正在处理冲突并重新部署…"，不再像卡住了一样。
- **批量「卸载」改叫「删除」**：按钮和确认文字说得更明白——删除后需要重新导入才能找回；只想暂时不用，请用「禁用」。
- **冲突面板删除重复项会先确认**，不再一点就删。
- **说明、图片、网页文件单独拖进来会直接跳过**，不会被当成 MOD 导入。
- **疑似游戏原版文件默认不导入**：把游戏自带的文件（如 `pakchunk0-Windows.pak`、官方补丁 `pakchunk26-Windows_P.pak`、`re_chunk_000.pak`）误拖进来时，导入确认里默认不勾选，并说明原因，避免启用后游戏打不开。
- **同名 MOD 会另存为新名字**，不会覆盖原来那个，提示也写清楚了。
- **非虚幻引擎游戏的压缩包识别更准**：Godot 的 .pck、暗黑破坏神 4 的 .mpq 等会被正确识别为 MOD 本体，装到对的位置。
- **游戏路径的盘符统一大写**（`d:\` 显示为 `D:\`），看着更整齐。
- **设置页滑动条看得清了**：背景透明度、模糊度的滑动条轨道清晰可见，拖过的部分会高亮，点轨道任意位置可直接跳过去。

## 问题修复

- **新版本提示终于能用了**：之前的版本读不懂服务器返回的版本信息，从来没提示过更新；现在有新版会在主窗口顶部提示，而且不开统计也能收到。
- 修复 MOD 卡片左下角的分类标签、文件大小被挡住看不到的问题。
- 修复卡片悬停时高亮边框四个角缺一块的问题。
- 修复设置页什么都没改、点「保存设置」却报错"仓库迁移失败"的问题。
- 修复导入后马上做冲突检测时，偶尔导致冲突结果错乱的问题。
- 修复同时保存多个设置文件时，偶尔把文件写坏的问题。
- 修复卡片右上角「⋯」菜单里「移动到分类」有时移动了别的 MOD 的问题。
- 修复右键点卡片上的电源按钮也会误触发启用/禁用的问题（现在只认左键）。
- 修复左侧「已启用 / 已禁用」等数量在筛选后不准、「全部 MOD」选中时文字颜色不变的问题。
- 修复联网时偶尔把已登录账号踢成未登录的问题。
- 修复设置页的统计开关显示与实际不一致、没碰过开关也会被保存成"开启"的问题。
- 修复在少数情况下，启用 MOD 时可能顺带改动 MOD 仓库里原文件的问题（仓库里那份现在始终保持独立）。
- 修复系统语言不同时，同一个 MOD 被认成两个不同 MOD 的问题（影响重复检测和冲突检测）。
