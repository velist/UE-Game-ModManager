# 爱酱 MOD 管理器 · 新手操作手册

适用版本：2.1.2 · 更新日期：2026-10-23

> 第一次用？从头往下照着做就行，每一步只做一件事。
> 核心功能不需要注册账号，不联网也能用。
>
> **一分钟速通**：安装 → 选 MOD 存放位置（别选 C 盘）→ 添加游戏 → 导入 MOD → 打开开关 → 点「启动游戏」一键部署开玩。

## 开始之前，先确认一件事

系统是 Windows 10 / 11 的 64 位版。

程序需要 **.NET 8 桌面运行时（x64）**。没装也没关系：安装向导会帮你检查，缺了会给出按钮，点它去微软官网下载安装，装完回来继续。

## 第 1 步：安装

1. 双击 `UEModManager_v2.1.2_Setup.exe`。
2. 按向导点「继续」，选安装位置，点「开始安装」。
3. 装完勾选「启动」；以后从桌面快捷方式打开。

## 第 2 步：第一次启动，只做两件事

打开后会遇到「MOD 存储设置」窗口：

1. **给 MOD 找个存放位置**（窗口右上角可切换中文 / EN）。这就是「MOD 仓库」，导入的 MOD 都先存在这里，不会和游戏文件混在一起。挑一个空间充足的盘，**最好不是 C 盘**（程序也不会推荐系统盘），点「使用此位置」。暂时不想选就点「以后再说」：电脑有别的硬盘时，程序会自动放到空间最大的那块（例如 `D:\UEModManager\Repository`）。之后可在「设置 → MOD 文件与位置」里改。
2. **添加游戏**：点左侧边栏顶部的「当前游戏」→ 选中你要玩的游戏。弹出「游戏路径配置」时核对两个路径，不对就点「浏览」改：

   | 项目 | 一般长这样（以黑神话·悟空为例） |
   |---|---|
   | 游戏安装路径 | `...\BlackMythWukong\b1\Binaries\Win64` |
   | MOD 文件夹路径 | `...\BlackMythWukong\b1\Content\Paks\~mods` |

   核对无误点「确认」。

> 进入主界面时会有一个 4 步的小引导（选游戏 → 导入 → 启用和管理 → 启动游戏），跟着点「下一步」就行，也可以按 Esc 跳过。它只出现一次。
>
> 打开程序不会弹登录窗口，不登录也能用。需要账号时点左侧边栏底部的「点击登录账号」。

## 第 3 步：导入 MOD

两种方式，选一种：

- **点顶部的「导入」按钮**，选压缩包或 MOD 文件。
- **拖进来**：把压缩包、文件夹或 MOD 文件直接拖进窗口。

注意事项：

- 支持 ZIP 压缩包、解压后的文件夹，以及 PAK 等文件。**RAR / 7Z 要先用 WinRAR 或 7-Zip 解压**，再把解压出来的东西拖进来。
- 一个 MOD 有多个文件时**一起导入**（全选后一起拖）。
- 导入后弹出「导入确认」窗口，上面写着每个文件将安装到哪里，核对后点「确认导入」。
- 有文件**默认没打勾**？那是程序觉得它像游戏自带的原版文件（误拖进来启用后游戏可能打不开）。确定是 MOD 就自己勾上。
- 重复导入同一个 MOD 会被拦下并提示，不会存两份；名字一样但内容不同的会另存为新名字，不会覆盖。
- 导入成功后右上角会冒出一条小提示。

## 第 4 步：启用 MOD

**导入不等于已经生效，还要启用。**

- 鼠标移到卡片上，点中间出现的电源按钮；卡片右上角小圆点变绿 = 已启用。
- 或者**点一下 MOD**，右侧滑出详情面板，里面也能开关。
- 要批量开关：先勾选（或用「全选」），再点顶部的「启用」/「禁用」。

> 改 MOD 之前，先把游戏关掉。

### 卡片左上角的标签是什么？

| 标签 | 意思 |
|---|---|
| **MOD** | 替换模型、贴图、音效的资源包，放进游戏的 MOD 文件夹 |
| **插件** | UE4SS、REFramework 这类加载器运行的脚本或 DLL，装在游戏目录里 |
| **配置** | 改游戏设置的 .ini / .json 等文件 |

列表上方的「全部 / MOD / 插件 / 配置」可以只看某一类（只有 MOD 时这排不显示）。

## 第 5 步：整理（可选，但很省心）

**点一下任意 MOD**，右侧滑出的详情面板里可以直接：

- 改名字：「编辑名称」
- 写备注：「编辑描述」
- 换预览图：点面板里的图片
- 改分类：「移动到分类」
- 删除：「删除」（会先弹确认）

其他小技巧：

- 左侧边栏「分类目录」管分类；右键 MOD 也有「移动到分类」。
- 「方案」= 不同的 MOD 组合存档（比如"画质档"和"战斗档"），在方案管理里双击即可切换，切换时会自动装进游戏；失败的话会留在原方案。
- 「删除」会连同管理器里保存的文件一起删掉，要重新导入才能找回；只想暂时不用，请点「禁用」。
- 顶部搜索框按名字找 MOD；右上角切换卡片 / 列表视图。

## 第 6 步：部署并启动游戏

1. 点顶部绿色的「启动游戏」按钮，打开启动中心。
2. 启动中心自动做启动前检查：有没有冲突、文件是否就位，然后自动部署。
3. 检查通过后点「启动游戏」，开玩。

> 「部署」= 把启用的 MOD 放进游戏目录。每次改完开关，走一遍启动中心最稳妥。

## 第 7 步：提示有冲突怎么办

- 卡片上出现**红色数字** = 这个 MOD 和别的 MOD 抢同一个文件。
- 右键 →「查看冲突」，或点顶部的「冲突检测」。
- 面板里一个冲突配一个按钮，按钮上写着 MOD 名（「只保留 X」或「禁用 X」），**点一下就好**，等"正在处理冲突并重新部署…"结束即可。
- 拿不准就点「禁用」，进游戏看效果，不满意再换一个。

## 常见问题

| 遇到的情况 | 怎么办 |
|---|---|
| MOD 装了没生效 | ① 开关是不是亮的？② 走一遍「启动游戏」让它部署；③ 是不是有冲突（看红色数字） |
| 游戏更新后 MOD 失效 | 正常，等 MOD 作者更新；游戏大版本更新可能重置游戏目录 |
| 禁用时提示「文件已被游戏更新」 | 选「交给游戏（推荐）」 |
| 拖进 RAR / 7Z 提示先解压 | 用 WinRAR 或 7-Zip 解压后再拖进来 |
| 想换个背景图 | 「设置 → 外观设置 → 背景模式」选「自定义图片」，还能调透明度和模糊度 |
| 想打开统计 | 默认是关的，「设置 → 常规参数 → 检查更新与匿名统计」打开即可；新版本提示不用开也有 |
| 提示缺少 .NET 运行时 | 按弹窗按钮去微软官网安装「.NET 8 桌面运行时（x64）」，装完重新打开 |
| 想换 MOD 存放位置 | 「设置 → MOD 文件与位置」 |
| 想搬去新电脑 | 先备份这两个目录：`%LOCALAPPDATA%\UEModManager\`、`%APPDATA%\UEModManager\`，以及你在用的 MOD 仓库目录 |
| 游戏目录被改乱了想恢复 | 点「存储与恢复」，里面有安装记录，可以回滚 |
| 想彻底卸载 | 控制面板卸载即可（用户数据和 MOD 仓库会保留）。要全清：运行安装目录里的「彻底清理UEModManager用户数据.bat」，先看它自己的提示 |

## 数据放在哪

| 内容 | 位置 |
|---|---|
| MOD 仓库（导入的 MOD） | 第一次启动时选的位置（跳过的话在非系统盘的 `UEModManager\Repository`） |
| 配置与索引 | `%LOCALAPPDATA%\UEModManager\` |
| 界面偏好 | `%APPDATA%\UEModManager\` |
| 日志（排查问题用） | `%LOCALAPPDATA%\UEModManager\Logs\` |
