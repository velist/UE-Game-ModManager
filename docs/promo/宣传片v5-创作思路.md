## 1. 创意定位

### 1.1 目标受众

**普通玩家，不是开发者。** 他们想给喜欢的游戏装 MOD，但不想研究 `~mods` 文件夹放在哪、
`.pak` 和 `.ucas` 有什么区别，也不想去改 `Engine.ini`。由此定下三条原则：

- **不讲技术名词，讲遇到的麻烦。** 「部署事务」「冲突检测」这些词只作为界面上的真实文字出现，
  大字文案全部用口语：「拖进来，就装好了」「出了错，一键回到原样」。
- **先让人认出自己玩的游戏，再介绍软件。** 玩家先被游戏画面吸引，然后才会关心工具。
  所以开头 3.6 秒全是游戏画面，品牌到 6.4s 才出现。
- **每个功能都要读得清。** 普通玩家不会暂停去看小字。界面必须在 1080p 下一眼看清，
  这也是 v5 最主要的改动（见第 3 节）。

### 1.2 核心信息

全片只传达两句话，其余内容都用来支撑它们：

1. **一个管理器，装下你所有游戏的 MOD。**（品牌副标题，6.4–10.5s）
2. **不止虚幻引擎。**（游戏墙，38.3s 起，后面跟着 6 个引擎标签）

第二句和产品定位一致：产品已经不只支持 UE，宣传中不能再写「专为虚幻引擎」。
引擎标签与 `GameConfigService.GetEngineType` 保持一致。

### 1.3 结构：为什么按这个顺序

```
钩子(0–3.6) → 痛点(3.6–5.05) → 一句话(5.05–6.4) → 品牌(6.4–11)
  → 五个功能(11–35) → 隧道(34.7–36.2) → 游戏墙(36–43.3) → 启动(43–47.5) → 收尾(47–52)
```

| 段落 | 解决什么问题 |
| --- | --- |
| 钩子 | 前 3 秒决定观众是否划走。玩家熟悉的大作画面快速切换，配一句提问「想给它们都装上 MOD？」，先让人愿意看下去 |
| 痛点 | 把「装 MOD 很麻烦」变成具体的报错弹窗，让观众觉得「我遇到过」 |
| 一句话 | 黑屏静音，只出一行字「装 MOD，不该这么难。」。前面越吵，这里的安静越有分量 |
| 品牌 | 痛点讲完立刻给出答案，品牌在情绪最低处出现 |
| 五个功能 | 按玩家实际使用顺序排列：**装进来 → 按场景切换 → 不打架 → 出错能回退 → 装多了能管理**。每个功能对应前面的一个痛点 |
| 游戏墙 | 回到核心信息：11 款开箱即用，不止虚幻引擎，还能自定义游戏 |
| 启动 | 给出最终结果：点「启动游戏」→ 直接进入游戏画面。前面所有功能都是为了这一下 |
| 收尾 | 品牌、标语、域名，以及打消顾虑的三个标签（Windows 10/11 · 免费使用 · 核心功能无需登录） |

痛点和功能是对应的：

| 痛点弹窗 | 对应功能 |
| --- | --- |
| 找不到 ~mods 文件夹 / 换个游戏又得从头找路径 | 01 导入（自动识别、自动归位）+ 游戏墙（11 款预设） |
| 两个 MOD 冲突，一启动就闪退 / Engine.ini 改了哪一行？ | 03 冲突（按启用顺序解决 + 配置文件合并） |
| 原文件被覆盖了，没留备份 | 04 安全（备份原文件 + 事务回滚） |
| 游戏一更新，MOD 全部失效 | 02 方案（一键切回纯净原版）/ 05 管理 |

情绪曲线：**兴奋（快切）→ 烦躁（报错堆积、画面抖动）→ 安静（黑场）→ 期待（品牌）→
平稳推进（功能）→ 抬升（隧道 + 游戏墙）→ 高潮（启动爆发）→ 落定（收尾）**。
配乐的响度安排也按这条曲线走（见 2.10）。

## 2. 逐场景拆解

时间单位为秒。场景时间窗定义在 `timeline.js` 的 `S`，相邻场景有 0.1–0.5s 重叠用于交叉过渡。
功能段固定从 `F_START = 11.0` 开始，每段 `F_DUR = 4.8`，下表中「+x」是该功能段内的本地时间。
音效写法：`名称@时间`，`L/R` 表示声像偏左/右。

### 2.1 钩子：游戏快切（0–3.6）

- **画面**：9 个镜头（`CUTS`）。第 1 镜黑神话：悟空 0.62s，第 2–8 镜各 0.42s
  （剑星、暗黑破坏神 IV、无主之地 4、光与影：33号远征队、识质存在、死亡搁浅 2、杀戮尖塔 2），
  第 9 镜明末：渊虚之羽从 3.56s 一直放到黑场，作为痛点段的底图。
  每次切镜画面从 1.11 倍回弹到 1.02 倍，同时有 0.28 强度的轻微闪白。
  左下角显示中英文游戏名，右下角显示序号「0n / 11」。
- **文案**：1.35s 弹出大字「想给它们都装上 **MOD**？」（outBack 回弹），3.57s 起模糊放大后消失。
- **情绪目的**：先让观众认出自己玩的游戏。切得快，表示游戏很多；提问让观众自然想到「对，我想装」。
- **剪辑细节**：剑星素材从 1.24s 开始取，因为 0.25–1.1s 整段是强光爆闪；剑星单独压暗到 `br: 0.85`。
- **音效**：`impact_intro@0.02` 开场一击；第 2–9 镜交替使用 `sword_swish`(L) / `trans_hit`(R)，
  声像左右交替，与快切节奏一致；`impact_deep@1.38` 配合大字落下。
- **配乐**：`legend.mp3` 从原曲 0s 开始，增益 0.42（较轻，给音效留出空间）。

### 2.2 痛点：报错堆满（3.62–5.05）

- **画面**：明末底图逐渐压暗（亮度 1.05→0.38）、去色（饱和度 1.1→0.2），并且越抖越厉害。
  从 `ERR_AT = 3.62` 起，每隔 0.17s 弹出一个报错窗口，共 6 个：

  | 标题 | 正文 | 小字 |
  | --- | --- | --- |
  | Mod Loader | 找不到 ~mods 文件夹 | `…\Content\Paks\~mods` |
  | 备份 | 原文件被覆盖了，没留备份 | `pakchunk0-Windows.pak` |
  | 游戏崩溃 | 两个 MOD 冲突，一启动就闪退 | `Fatal error: [File:Unknown]` |
  | 配置 | Engine.ini 改了哪一行？ | `[SystemSettings] r.???` |
  | 版本 | 游戏一更新，MOD 全部失效 | `Version mismatch` |
  | 路径 | 换个游戏，又得从头找路径 | `\steamapps\common\???` |

  4.75–5.15s 抖动加剧，5.0–5.3s 弹窗出现故障效果（横向错位、色相偏移、模糊）后消失。
- **情绪目的**：让观众烦躁，并认出这些都是自己遇到过的问题。弹窗正文是玩家口语，
  小字是真实路径和报错，两者都有，增加真实感。
- **音效**：6 声 `game_notify`，声像按 L/R/中 交替，音量逐个增大（0.24→0.34），表示问题越积越多；
  `whoosh_stutter@4.80` 配合故障效果。

### 2.3 一句话：黑场（5.05–6.45）

- **画面**：5.05–5.32s 压成全黑。5.38s 出现「装 MOD，」，5.62s「不该这么**难**。」放大落下，
  「难」字在 5.92–6.2s 抖动一下。6.38s 一道闪白切到品牌。
- **情绪目的**：从最吵到最安静。这句话是全片的观点，所以只给它这一个画面。
- **配乐**：**底乐在 5.05s 直接切断**（40ms 斜坡，不淡出），让这句话落在安静里。
  只用打击音标出两段文字：`impact_deep@5.40`（前半句）、`impact_big@5.64`（后半句），
  `trans_riser@5.70`（跳过 0.6s 前摇）把情绪推向品牌。

### 2.4 品牌揭示（6.30–11.05）

- **画面**：AI 主视觉 `gen/hub.png`（中央是青色六边形水晶，周围环绕的玻璃碎片里是各种游戏世界）
  在 6.3–10.3s 从 1.22 倍缓慢推到 1.04 倍。
  6.75s 光晕亮起 → 6.85s 光环扩散 → 6.75–7.45s logo 从模糊中回弹出现 →
  7.25–7.95s 品牌名字距从 46px 收到 10px → 7.9s 副标题「一个管理器，装下你所有游戏的 MOD」。
  10.1s 文字退场，10.25–11.0s 镜头冲进中心水晶（放大 3.4 倍并模糊、提亮），10.95s 闪白进入功能段。
- **情绪目的**：给出答案。hub 图的设计（一个核心连接许多游戏世界）就是「一个管理器装下所有游戏」的画面表达。
  最后冲进水晶，意思是「进入软件内部」，自然转到功能演示。
- **音效**：`whoosh_cine@6.25` → `impact_logo@6.38`（全片第二重的单个音效，增益 0.72）→
  `magic_sparkle@7.25` 配合品牌名展开 → `whoosh_tunnel@10.30` 配合冲入 → `impact_deep@10.96`。
- **配乐**：主底乐 6.30s 从**原曲 16.0s** 接入，0.25s 淡入，增益 0.72。选 16.0s 有两个原因：
  原曲在这里正好进入主题段；更重要的是这样对齐后，原曲结尾刚好落在片尾（见 2.10）。

### 2.5 功能 01 导入：悟空（11.0–15.8）

- **背景**：`stills/wukong-shot2.jpg` 虚化。
- **文案**：编号「01 — 导入」｜大字「拖进来，/ 就装好了」｜副标题「压缩包、整合包、.pak / .ini / 自动识别，自动归位」。
- **界面演示**（窗口「导入 MOD / 插件 · 步骤 1/2」）：
  +0.45–1.35 光标拖着「黑神话_画质增强整合包.zip · 286 MB · 3 个文件」沿弧线飞入拖拽区，拖拽区亮起 →
  +1.6 起逐行列出检测结果（两个 `.pak`、一个 `Engine.ini`，注明「将进入配置文件合并」）→
  +2.1–3.3 进度条「正在导入 1/3…3/3」→「完成」→ +3.35「✓ 已导入 3 项，去「全部 MOD」里一键启用」。
- **情绪目的**：第一个功能讲最基础的需求：拖进去就能用，不用找路径。
- **音效**：`whoosh_air@+0.55`（文件飞入）、`ui_confirm@+1.38`（落下）、`game_tap`×3 @+1.62 起每 0.2s（逐行识别）、
  `game_complete@+3.36`（完成）。

### 2.6 功能 02 方案：剑星（15.8–20.6）

- **背景**：`stills/stellar-shot0.jpg`。
- **文案**：「02 — 方案」｜「一套方案，/ 一键切换」｜「剧情向、截图党、纯净原版 / 想怎么玩，点一下就换」。
- **界面演示**：仿真主窗口，左侧「MOD 配置方案」，右侧 6 张带缩略图的 MOD 卡片
  （Eve 战斗服 · 夜鹰、HD 材质包 4K、电影感滤镜、剧情跳过增强、自动拾取、拍照模式解锁）。
  光标依次点击：+1.35 截图党（3 个）→ +2.65 纯净原版（0 个）→ +3.9 回到剧情向（4 个）。
  每次切换，卡片开关按顺序错开 45ms 翻转，关闭的卡片变灰变暗，打开的卡片闪一下。
- **情绪目的**：表达「同一个游戏可以有几种玩法，切换不用重装」。最后切回剧情向，形成一个完整的循环。
- **音效**：每次点击 `ui_select`（L），0.12s 后 `game_tap`（R）表示开关翻转。点击声和开关声左右分开，听起来是两个动作。

### 2.7 功能 03 冲突：光与影（20.6–25.4）

- **背景**：`stills/exp33-hero.jpg`。
- **文案**：「03 — 冲突」｜「谁覆盖了谁，/ 一眼看清」｜「冲突检测列出每个来源 / 配置文件自动合并，不再互相打架」。
- **界面演示**（窗口「冲突检测」，徽标「潜在冲突 2」）：
  +0.45 起两张冲突卡片依次出现 → +0.9–1.9 扫描线自上而下扫过 →
  +2.0 文件冲突 `~mods/Gustave_Outfit_P.pak` 按启用顺序解决（#7「经典套装合集」生效，#3 变灰）→
  +2.5 配置冲突 `Engine.ini · [SystemSettings]` 两个来源合并（「2 处设置已并入」）→
  +3.0 徽标变成「无阻塞冲突」→ +3.1「✓ 未发现阻塞冲突，可以放心启动」。
- **情绪目的**：直接回应痛点里的「冲突闪退」和「Engine.ini 改了哪一行」，演示两种不同的处理方式（覆盖、合并）。
- **音效**：`tech_zoomin@+0.9`（扫描），`ui_confirm` 在 +2.0(L) 和 +2.5(R) 各一次，对应左右两张卡片，`game_complete@+3.1`。

### 2.8 功能 04 安全：生化危机9（25.4–30.2）

- **背景**：`stills/re9-hero.jpg`。
- **文案**：「04 — 安全」｜「出了错，/ 一键回到原样」｜「部署按事务写入，失败自动回滚 / 报错说人话，原文件一个不丢」。
- **界面演示**（窗口「部署到游戏 · 生化危机9 · 方案：默认」）：
  ✓ 备份原文件 12 个 → 写入 MOD 文件进度 0→19 / 31 → **+1.75 失败**，进度条变红 →
  +1.85 错误卡片晃动着弹出：「部署没有完成 — 游戏好像还开着，有文件被它占用了。先关掉游戏再试一次就好——
  *刚才写了一半的改动已经自动撤回。*」→ +2.4–3.3 回滚进度 0→19 / 19 →
  +3.4「✓ 已回到部署前的状态 · 游戏文件完好」。
- **情绪目的**：五个功能里唯一**故意演示失败**的一段。普通玩家最怕「装坏了」，
  直接展示出错和恢复的过程，比只说「很安全」更可信。错误文案对应 v2.1.1 的「错误白话化」。
- **音效**：`trans_metal@+1.75`（失败的金属撞击声）、`tech_zoomout@+2.4`（回滚，与扫描音效 zoomin 相对应）、`game_complete@+3.4`。

### 2.9 功能 05 管理：暗黑破坏神 IV（30.2–35.0）

- **背景**：`stills/diablo4-hero.jpg`。
- **文案**：「05 — 管理」｜「装得再多，/ 也井井有条」｜「分类、备份、清理未使用 / 一个窗口全部搞定」。
- **界面演示**（窗口「高级管理」，标签页：已导入 MOD / 安装记录 / 配置文件合并 / 临时文件）：
  +0.4–1.4 统计数字增长到 2.4 GB · 48 个 MOD · 5 个未使用（黄色警示）；
  分类条形图依次展开（服装 18 / 玩法 12 / 画质 9 / 插件 6 / 未分类 3）→
  +1.7–2.45 光标移到「清理未使用」→ +2.55 点击 → 未使用数降为 0、变成绿色 → +2.9「已释放 820 MB」。
- **情绪目的**：最后一个功能回答「装多了怎么办」。数字增长带来「装了很多」的感觉，清理带来轻松感。
- **音效**：`ui_posbeep@+0.45`（统计开始）、`ui_select@+2.55`（点击）、`game_coin@+2.75`（空间被释放）、
  `magic_glitter@+2.9`（跳过 0.5s 前摇）。
- **功能之间的转场**：后一段比前一段提前 0.12s 响 `whoosh_fast`（R）；画面上，前一段文字向左退出、窗口向左转并模糊，
  后一段的窗口从右侧 3D 斜着进入（rotateY −24°→−9°），然后在整段时间里慢慢转正。

### 2.10 隧道转场（34.65–36.25）

- **画面**：AI 图 `gen/tunnel.png`（由游戏卡片和文件图标组成的隧道，中心有亮点）放大 1→2.6 倍并旋转 6°，
  叠加放射线，36.08s 闪白。
- **情绪目的**：功能段是「讲道理」，这里转回「讲气势」，像一次加速，把观众带到全片最满的游戏墙。
- **音效**：`whoosh_rocket@34.70`、`impact_epic@36.06`。

### 2.11 游戏墙（35.95–43.30）

- **画面**：3 行 × 9 列的 3D 卡片墙（倾斜视角，三行以 70 / −55 / 90 px/s 向不同方向滚动），
  包含 11 款内置游戏（每张卡片标注游戏名和引擎）和一张「＋ 自定义游戏」卡片。入场用 1.4s outExpo 从远处推近。
  文案：36.2s「**0→11** 款游戏 / 开箱即用」（36.4–37.7s 计数，37.55s 数字跳一下）→
  38.3s「不止虚幻引擎」→ 38.65s 起每隔 0.14s 弹出一个引擎标签：
  Unreal Engine / RE Engine / Decima / Godot / 暴雪自研引擎 / Unity →
  39.9s「＋ 自定义游戏，指定引擎即可接入」。42.3s 文案退场，42.5–43.3s 墙面整体向镜头冲过来，43.1s 闪白。
- **情绪目的**：全片画面最满、声音最大的一段，直接给出第二个核心信息。
  Unity 没有对应的内置游戏，放在标签里是因为自定义游戏可以选它，后面紧跟「自定义游戏」一行作为解释。
- **音效**：`impact_epic@36.06` 落地 → `game_tap`×6 从 36.45s 起每 0.2s 一声并逐渐变响（配合计数）→

### 2.14 整片响度（`make-audio.mjs` 总线自动化）

| 时间 | 增益 | 原因 |
| --- | --- | --- |
| 0–5.05 | 底乐 0.42 | 钩子段让音效为主 |
| 5.05–6.30 | 底乐静音 | 黑场一句话 |

## 3. 从 v4 到 v5：取舍与教训

### 3.1 v4 留下的问题

v4（46.5s）的结构是：痛点 → 品牌 → 主界面 → 导入 → 冲突 → 16s 多游戏轮播（5 款宣传片 + HUD）→ 启动 → 收尾。主要问题：

1. **界面看不清。** 应用窗口只占画面很小一块，字在 1080p 下读不出来。观众只能看到「有个软件界面在动」，看不到它在做什么。
2. **游戏太少，而且开头不吸引人。** 只有 5 款游戏，并且放在中段；开头 4.6s 是文字痛点，前 3 秒没有能抓住人的画面。
3. **多游戏段太长。** 16 秒用来让宣传片镜头展开，HUD 叠在虚化区域里，信息密度低。
4. **配乐分两段**：前段 `tech_ambient` 氛围音，15.2s 再接管弦乐。这样做本身是合理的（软件演示段铺管弦乐，听起来像游戏宣传片配乐），但两段之间要靠精确的交叠来衔接。

### 3.2 v5 的改动

| 改动 | 具体做法 | 原因 |
| --- | --- | --- |
| **界面放大** | 每个功能单独一屏：左边 100px 大字标题 + 34px 副标题，右边 980px 宽的窗口，正文 20–26px | 普通玩家不会暂停，必须一眼看清 |
| **钩子改成游戏快切** | 开头 3.6s 切 9 个镜头，痛点改成叠在游戏画面上的报错弹窗 | 前 3 秒先用熟悉的游戏画面留住人；痛点有了具体场景 |
| **游戏画面 5→10 款** | 新增暗黑4、无主之地4、识质存在、死亡搁浅2、杀戮尖塔2 的片段与截图；功能段每段换一款游戏做背景；游戏墙列出全部 11 款 + 自定义 | 用画面说明「所有游戏」「不止 UE」，不只靠文字 |
| **去掉长轮播** | 16s 多游戏段改为：5 个功能各用一款游戏背景 + 7.35s 游戏墙 | 游戏画面分散到全片，不再集中在一段 |
| **AI 主视觉** | hub（品牌）、tunnel（转场）、outro（收尾）三张生成图 | v4 的品牌段和收尾只用 CSS 光效，没有主视觉图；AI 图提供气势，品牌元素仍由页面叠加，保证字体和色值准确 |
| **配乐改为一首曲子用到底** | 不再用 `tech_ambient`；`legend.mp3` 钩子段取开头，黑场静音，品牌处从 16.0s 接入 | 结构上有黑场作为自然断点，不需要两种音乐交接；同时让原曲结尾对齐片尾 |
| **功能段补 3dB** | 11.2–34.6s 总线 ×1.4 | 原曲中段偏安静，v5 功能段正好落在这一部分 |
| **结尾自然收束** | 用接入点 16.0s 反推，让原曲 60.5–63s 的收尾落在 50.8–53.3s | 管弦乐结尾硬切或强行淡出都很明显 |
| **演示「失败」** | 新增 04 安全：故意演示部署失败和回滚 | 普通玩家最担心装坏，展示恢复过程比口头承诺可信 |
| **新增方案、管理两个功能** | 02 方案切换、05 高级管理 | 补全「装进来之后」的使用场景 |

### 3.3 沿用下来的 v4 经验（不要再踩）

- **渲染契约**：`renderAt(t)` 是纯函数，不用 CSS transition，**永远不调用 `video.play()`**，
  视频靠设置 `currentTime` 并等待 `seeked` 来定位。静态服务器必须支持 Range 请求。
- **素材片段的时长约束**：seek 时间不能超过片段实际长度（v5 的 `seekVideo` 会夹到 `duration − 0.04`）。
  换片段时要核对 `off + d` 是否超出片段长度，否则画面会停在最后一帧。
- **片段统一转成全关键帧**（`-g 1`）：逐帧 seek 又快又准。
- **先提亮再模糊**：游戏画面普遍偏暗，直接模糊会变成一片黑。
- **不要用硬边分割画面**：虚化和遮罩要作用在同一个元素上，否则会留下硬边。
- **动画时间按比例或本地时间写**：v5 的功能段统一使用本地时间 `L`，整段平移只需改 `F_START`。
- **音效自动跳过前摇**：`onsetSeconds()` 让 `cue.t` 对应「听到声音的那一刻」，手写时间时不用自己减前摇。
- **侧链闪避最多 22%**：压得太深，最满的段落反而会变成低谷。
- **Mixkit 的音乐不能用**（授权禁止用于「Video Games」），只能用它的音效。
- **logo 要先跑 `clean-logo.mjs`**，去掉 alpha≈2 的透明残留，否则加 drop-shadow 后会出现方形暗块。

### 3.4 v5 新踩到的坑

- `download-more.mjs` 偶尔会留下缺少 moov 的不完整 mp4，删掉后重跑即可。
- 补充宣传片普遍有黑边或烧录字幕：用 `cropdetect` 实测裁切值；识质存在裁掉底部字幕后再放大。
- 剑星片段 0.25–1.1s 是强光爆闪，快切时要避开。
- `gpt-image-2-skill` 走 Codex 时，ChatGPT 账号会被拒绝；改为直接 `codex exec` 调用内置生图工具（见第 6 节）。

## 5. 复用指南

### 5.1 必须同步的不变量

| 改了这里 | 必须同步 | 原因 |
| --- | --- | --- |
| `timeline.js` 的 `S`、`F_START`、`F_DUR`、各 `seg(...)` 时间点 | `make-audio.mjs` 的 `CUES`（以及 `F = i => 11.0 + i * 4.8`） | 音效时间是手写的绝对秒数，不会自动跟随画面 |
| `timeline.js` 的 `CUTS`（镜头数、`d`） | `make-audio.mjs` 的 `CUT_STARTS`、`ERR_AT` | `CUT_STARTS` 是手写的数组，没有从 `CUTS` 推导 |
| 黑场时间（`timeline.js` 中 5.05） | `HOOK_BED.end` | 底乐必须在黑场的同一时刻切断 |
| 品牌进场时间 | `MAIN_BED.at` / `MAIN_BED.ss` | 改动后原曲结尾不再对齐片尾，需要重新推算 `ss`：**片尾 ≈ at + (60.5 − ss)** |
| `DURATION`（`timeline.js`） | `scripts/render.mjs` 的 `DURATION`、`make-audio.mjs` 的 `DUR`、`encode.mjs` 文件名里的「52s」、poster 取帧号 `f01500` | 这几处都是分别硬编码的 |
| 功能段的位置 | `make-audio.mjs` 总线自动化中 11.2–12.5 / 34.4–34.8 两处 +3dB 开关 | 补偿只应作用于功能段 |
| 片段 `off + d` 或启动段 seek 起点 | 片段实际长度 | 超出后画面会停在最后一帧 |
| 引擎标签、游戏列表 | `GameConfigService.GetAvailableGames` / `GetEngineType` | 宣传内容不能和产品实际支持不符 |
| 增删游戏 | `CUTS`、`WALL_GAMES`、`montIdx` 的「/ 11」、游戏墙计数「11」、`fetch-more.mjs` 的 `GAMES` | 游戏数量分散写在多处 |

改完后的检查顺序：`make-audio.mjs` → `preview.mjs <关键时间点>` 看拼版 → 全片渲染 → `volumedetect` 复核响度。

### 5.2 做新版本（例如 v6）

1. 复制 `tools/promo/v5/` 为 `v6/`。`render-lib.mjs` 与 `clean-logo.mjs` 位于 `tools/promo/`，被共用；脚本里的相对路径以 `v5/` 为基准，需要整体替换。
2. **先定结构再动代码**：沿用「钩子 → 痛点 → 一句话 → 品牌 → 功能 → 游戏墙 → 启动 → 收尾」，
   只替换功能段的内容。新增功能时一屏只讲一件事，文案保持「大字口语 + 副标题说明」的写法。
3. 功能段如果改成 6 段，`F_DUR × 段数` 会改变总时长，后面所有场景要整体顺延，参照 5.1 逐项同步。
4. 如果换底乐，先找到原曲「自然收尾」的位置，再反推接入点，让收尾落在片尾，不要用硬切或淡出凑结尾。

### 5.3 做竖屏版（1080×1920）

v5 目前**没有竖屏版**。v4 竖屏版的做法（`tools/promo/render-vertical.mjs`、`make-audio-vertical.mjs`，20s）可以参考：

- **单独剪成 15–20s 的短版，不要直接把 52s 改成竖屏**。短视频平台需要更早出现结果。建议保留：
  钩子快切（缩到约 2s）→ 一句话 → 品牌 → 选 1–2 个最直观的功能（导入、回滚）→ 游戏墙计数 → 启动 → 收尾。
- **布局**：功能段左右分栏改为上下分栏（上方大字，下方窗口），窗口宽度约 960px，正文字号不能缩小。
- **游戏素材**：横版片段居中裁成 9:16 会丢失大部分画面，建议把片段放在上半屏，或改用竖构图的截图。
- **AI 图**：hub/tunnel/outro 需要重新生成竖版（提示词把 `landscape 16:9` 改为 `portrait 9:16`，
  hub 的「下三分之一保持暗」改成「下半部分」）。
- **音频**：需要单独的 `CUES` 与底乐接入点，同样遵守「原曲结尾对齐片尾」。
- 新建 `v5/vertical/` 或单独的入口 HTML，不要在横版的 `timeline.js` 里用分支判断。
