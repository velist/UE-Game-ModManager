# 爱酱 MOD 管理器 · 快速上手

版本：2.1.2 · 2026-10-23

1. **安装**：需要 Windows 10 / 11 64 位环境和 .NET 8 Desktop Runtime（x64）。安装向导会检查运行时。
2. **选仓库**：首次启动选择 MOD 存储位置，可与程序安装目录分开，建议选非系统盘。首次进入主界面会有 4 步引导，可跳过。
3. **选游戏**：核对游戏路径与 MOD 部署位置，核心管理无需登录。
4. **导入 MOD**：点“导入”，或把 ZIP 压缩包、文件夹、PAK 等文件拖进窗口。RAR / 7Z 请先解压。
5. **启用与启动**：卡片左上角标明 MOD / 插件 / 配置。核对后启用，确认部署成功，再启动游戏。修改 MOD 前先关闭游戏。

## 数据在哪里？

- 本机配置和索引：`%LOCALAPPDATA%\UEModManager\`
- 界面偏好和账号数据：`%APPDATA%\UEModManager\`
- MOD 仓库与备份：以首次启动或设置中选择的位置为准。
- 日志：`%LOCALAPPDATA%\UEModManager\Logs\`

换电脑或重装前，分别备份两个用户数据目录及实际仓库、备份目录。普通卸载保留这些数据。

匿名统计默认关闭，可在“设置 → 常规参数”中打开；新版本提示不受影响。
